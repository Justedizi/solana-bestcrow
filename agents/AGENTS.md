# Agent entry point

**Read the rules and criteria PDFs in `docs/` first. They are the highest-priority project requirements and override conflicting proposals, summaries, skills, reference code, and MCP guidance.** Follow the source priority and conflict-handling procedure in the root [AGENTS.md](../AGENTS.md). Cite the relevant PDF filename and page/section when a requirement affects a decision.

Then read `agents/PROJECT.md` for the item marketplace idea, scope proposals, and worst cases, and `agents/CONTEXT.md` for the hackathon summary and repository map. These documents are subordinate to the PDFs. The current direction is a buyer/seller marketplace; freelancer milestone escrow is reference material.

Read `agents/INSTRUCTIONS.md` for local MCP setup. Commands there run from the repository root.

For library/API documentation, use the Context7 workflow in those instructions and match the actual project's dependency versions. Use the official Solana MCP for additional Solana and Anchor guidance.

Treat code under `context/` as external reference material unless an explicit project decision adopts it. Distinguish proposed, implemented, and verified behavior in handoffs.

Keep responses clear and brief: lead with the result, label assumptions, and give one concrete next action when needed.
